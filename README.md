# 자기 전에 뭘 보면 잠을 망칠까?

**자기 전 사용하는 앱 유형에 따른 수면 영향 분석** — 대학 '데이터분석' 과목 기말 프로젝트

어차피 자기 전에 폰을 볼 거라면 수면에 영향을 덜 주는 앱 유형이 있는지, 라이프로그 데이터셋으로 분석하는 프로젝트이다.

## 질문
| 어떤 앱 유형이 수면 지표와 더 관련이 있는가?

## 데이터셋

[ETRI 라이프로그 데이터셋 2024](https://epretx.etri.re.kr/epretx/dataDetail?lang=ko&id=459)를 사용한다.

- 원 연구 규모: 참가자 50명 X 12주 (스마트폰·스마트워치·수면 센서·자기보고 앱)
- 실제 공개 규모: 참가자 10명, 총 700일

아래는 12개 센서 데이터와 수면 지표 항목이며 비상업적 학술 연구 목적으로만 이용이 가능하다.

| 출처 | 주요 변수 |
|---|---|
| 스마트폰 | 앱 사용, 화면 상태 |
| 스마트폰 | 충전 상태, 활동, 주변 조도, 주변 소리 |
| 스마트폰 | GPS, 블루투스, Wi-Fi |
| 스마트워치 | 심박, 주변 조도, 걸음 수 |
| 수면 센서 | 총 수면 시간, 수면 효율, 입면 잠복기의 권고 부합 여부 |
| 자기보고 | 주관적 수면의 질, 취침 전 피로·스트레스 |

| 지표 | 의미 |
|---|---|
| Q1 | 일어나서 느낀 수면의 질 |
| Q2 | 자기 전 피로도 |
| Q3 | 자기 전 스트레스 |
| S1 | 총 수면 시간 권장 기준 충족 |
| S2 | 수면 효율 권장 기준 충족 |
| S3 | 잠들지 전까지 걸린 시간 권장 기준 충족 |

## 앱 유형

앱을 메신저, 웹·포털, 동영상, SNS, 게임, 웹툰, 음악, OTT 등의 유형으로 묶어서 비교한다.

## 한계

- 참가자 수가 많지 않아, 일반화에 주의가 필요하다.
- 수면 센서 지표는 권장 기준 부합 여부이므로 수면 시간이 얼마나 늘거나 줄었는지는 판단하지 않는다.
- 폰을 봐서 잠이 안 오는 건지, 잠이 안 와서 폰을 보는 건지 구분하기 어렵다.
- 주관적 수면의 질은 개인 평균을 기준으로 삼으므로 참가자 간 비교에 쓰지 않는다.
